What testing in game changed

Updated Nov 6, 2026, from Assist Companion debug logs, game data and sims of the addon's rules
  • Enemy counts work in combat when enemy nameplates are on: the addon counts attackable enemies in range or in combat. Every target count gap below is addon-fixable. The in-game highlight counts enemies on its own (it switches to AoE spells without nameplates).
  • Runic power is hidden from addons (secret value), while runes and essence still read. Runic power threshold fixes still work: the addon hands the threshold to the game, which shows or hides the icon (confirmed on Unholy and Blood). Check each spec's resource before assuming a "spend at cap" rule can compare numbers.
  • Devastation's Azure Sweep gap is a SimC artifact: SimC's Azure Strike refuses to fire while the Azure Sweep buff is up, so the highlight's "Azure Strike while Azure Sweep is up" rule never fires in the sim. In game the button casts Azure Sweep. Devastation's real gaps are essence waste, Pyre at 3 targets and empower ranks. Unbound Flame (0 highlight casts) is likely the same kind of artifact: the highlight's rule is "Dragonrage while Unbound Flame is up", and in game that button casts Unbound Flame. Not yet confirmed in game.
  • Being in the highlight's list doesn't mean it gets suggested. Debug logs showed the in-game highlight never suggested Devastation's Dragonrage, Deep Breath and Tip the Scales, or Augmentation's Tip the Scales, Time Skip and Breath of Eons, though all are in its list. So the cooldowns never suggested counts below (from SimC) are a floor. Check each spec in game before trusting them.
  • Talents change the timings. Cooldown cuts like Wingleader, Onyx Legacy, Chronoboon or Interwoven Threads, and talents that stretch a buff (Animosity, Rising Fury), move when a cooldown is really ready. Assist Companion now keeps a per-class talent, racial and mastery database from game data to catch these before a spec ships.
  • Simmed: what the addon recovers on Devastation. The addon's rules written as a SimC action list on top of the highlight's own list (Patchwerk, 3,000 iterations, SimC's Scalecommander and Flameshaper builds). Loss vs the optimal rotation:

    "In game" drops the cooldowns the highlight never suggests, and presses the button overrides that SimC's version misses (Azure Sweep, Unbound Flame). Every empower is cast at max rank, because the highlight never names a rank. Of the addon's gain on top of the cooldowns, the empower rank badge is nearly all of it (+13 to +45%). Essence cap adds about 1%. Flameshaper at 5 targets beating optimal means SimC's own list isn't perfect there. This is a model of the rules, not the addon itself, and the debug logs confirm it in game.
  • Covered by Assist Companion: Blood, Frost and Unholy Death Knight, Devastation and Augmentation Evoker (Augmentation isn't in this table: its losses need raid sims with allies). Evoker is finished as of 0.21.6 and was tested on dummies and in a raid. Death Knight is next.
